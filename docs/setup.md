# Local Setup Guide

## Requirements

Install the following software:

- Git
- .NET 10 SDK
- Node.js LTS and npm
- SQL Server Express
- SQL Server Management Studio
- An Azure account with access to Azure AI Foundry

```powershell
git clone https://github.com/Rael2004/midis-ai-sql-assistant.git
cd midis-ai-sql-assistant
